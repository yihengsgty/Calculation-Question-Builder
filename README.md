# Calculation-Question-Builder
一个用来创建小学计算题的工具，支持把题目与答案打印到文件

事件起始原因：我15岁，我弟弟比我小七岁，有一天他因为平板没有带回家，所以在家里发脾气，我妈妈让我拿一些计算题给他做，但是我懒得一道题一道题编，于是我写了一个C++程序来生成。最开始默认生成100题0～100以内的，然后最近突发奇想，把代码做了亿点点优化。我最开始的代码：

#亿点点“灵魂拷问”
>问：那么加了什么功能？
>答：自己去看代码。如果看不懂或懒得看，我直接告诉你，一个是“选择题目数量”，一个是“选择题目出题范围”，”，一个是“答案取值下限”，最后一个是“答案取值上限”……

>问：你确定你才15岁？
>答：这个问题不要乱问，我确实15岁，但是我不想被开盒。

>问：代码存在风险吗？
>答：基本不存在。程序只是往你的/storage/emulated/0/Documents下创建了一个文件，这个文件本身人畜无害，只会存放题目与答案。

>问：涉及到自动生成，占手机空间吗？
>答：想什么呢，又不是AI大模型生成。整个程序大概也就……2MB左右吧。

>问：看了代码感觉前面的验证挺正式的。
>答：确实正式，但只是表面上正式。实际上这个程序压根不危险。验证只是给用户的定心丸而已。
